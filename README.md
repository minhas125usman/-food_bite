# 🍕 Quick Bite Food Website

**Quick Bite Food** is a modern and responsive food-themed website built using **HTML, CSS, and JavaScript**.
It is designed to showcase menu items, promote food services, and provide an interactive user experience.

---

## 🚀 Features

✅ Responsive and mobile-friendly layout
✅ Clean and modern UI design
✅ Menu section with food items and images
✅ Add to Cart functionality using JavaScript
✅ Category filters (Breakfast, Lunch, Dinner, Desserts, Drinks)
✅ Search bar to quickly find items
✅ Smooth hover animations and CSS transitions
✅ Header, Menu, About, Contact, and Footer sections

---

## 💻 Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Google Fonts
* Font Awesome Icons


3. Run the project:

Open `index.html` in your browser (or use VS Code Live Server for live preview).
